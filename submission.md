# 🦥 The Notification & Info Overload Tamer (The Sloth Agent)
> *Sleep in. Conserve energy. Wake up to an exact 2-line executive brief while open-weight AI sifts through the noise overnight—running 100% locally with zero cloud data leaks.*

---

## What I Built

Modern developers and knowledge workers suffer from chronic **notification fatigue**. Every morning begins with 300+ unread badges across Slack, Discord, WhatsApp, Telegram, and tech feeds: 85% is memes, lunch polls, weekend banter, and bot noise, while 15% contains critical production alerts, PR review freezes, client deadlines, and urgent mentions.

I built **The Sloth Agent (InfoTamer)** to honor International Sloth Day by taking the slow, steady, and gloriously lazy path:
- **Silently hoards and digests unread notifications overnight** while you sleep.
- **Pre-LLM PII Sanitizer:** Automatically masks emails, phone numbers, secret API tokens, and IP addresses before model processing.
- **Three-Stage Local AI Pipeline:** Triages signal from noise, extracts concrete action items (`who`, `what`, `by when`), and synthesizes a **hyper-concise 2-line Morning Executive Summary (TL;DR)**.
- **Zero Cloud Invocations:** Runs entirely on consumer hardware (Apple Silicon Mac, local GPU, or Raspberry Pi 5) using **Google Gemma 2 2B Instruct** via Ollama.

**Who gets to be lazy?** Anyone who dreads opening communication apps in the morning. Instead of spending 35 minutes scrolling through threads, you read two sentences over coffee and immediately know if servers are on fire or if you can take your morning slow.

## Code

The complete source code is open source on GitHub:

🔗 **[GitHub Repository: a1rya9n/InfoTamer](https://github.com/a1rya9n/InfoTamer)**

The repository includes modular, production-ready Python modules:
- `ingestor.py`: PII sanitization engine, multi-channel simulator, and SQLite retention buffer.
- `processor.py`: Multi-stage Ollama client with structured JSON schema outputs and offline fallbacks.
- `reporter.py`: Brief generator producing the 2-line summary, markdown reports, Rich terminal tables, and macOS desktop notifications.
- `main.py`: CLI and APScheduler overnight background daemon.
- `test_gemma.py`: Diagnostic test harness for local Gemma 2 models.

## How I Built It

### 1. Open-Source AI Engine: Google Gemma 2 2B Instruct (`gemma2:2b`)
I chose **Google Gemma 2 2B Instruct** because it is uniquely engineered for high performance on edge hardware:
- **VRAM Footprint:** Only **~1.6 GB**, allowing it to run smoothly on Apple Silicon unified memory, Linux workstations, or a Raspberry Pi 5 without competing with other system tasks.
- **Architectural Efficiency:** Sliding window attention combined with grouped-query attention provides top-tier instruction following and structured JSON parsing in a compact parameter space.

### 2. Local Inference Runtime: Ollama
Inference runs locally via Ollama (`http://localhost:11434`) using native Metal/CUDA acceleration with strict JSON output formatting (`format: "json"`).

### 3. Three-Stage Pipeline Architecture

```
[ Incoming Notifications ]
          │
          ▼
┌──────────────────┐
│  PII Sanitizer   │  --> Masks tokens, emails, phone numbers, and IPs
└─────────┬────────┘
          ▼
┌──────────────────┐
│ Stage 1: Triage  │  --> Classifies into critical_alert, action_required, noise, etc.
└─────────┬────────┘
          ▼
┌──────────────────┐
│ Stage 2: Actions │  --> Extracts who, task, deadline, urgency, and mentions
└─────────┬────────┘
          ▼
┌──────────────────┐
│ Stage 3: Brief   │  --> Synthesizes strict 2-line TL;DR + Markdown digest
└─────────┬────────┘
          ▼
[ Terminal UI + Markdown File + macOS Desktop Push Notification ]
```

### 4. Zero-Leakage Privacy Policy
- **Local SQLite Store (`./data/infotamer.db`):** All records reside in a local SQLite file restricted to POSIX `0600` permissions.
- **Rolling Auto-Purge:** Raw message records older than 48 hours are automatically purged to prevent unbounded storage and eliminate retention risk.

## Why Does Open Innovation Matter?

Consider the alternative: feeding your personal Discord servers, WhatsApp family group chats, private Slack engineering channels, and internal server credentials into a closed, proprietary cloud LLM API.
1. **Confidentiality & Compliance:** Sending unredacted workplace chat transcripts to third-party cloud servers violates confidentiality agreements and data protection laws.
2. **Local Sovereignty:** Open-weight models like **Google Gemma 2** give individuals complete data sovereignty. The model runs on *your* silicon, reads *your* local database, and never sends a single byte across the internet.
3. **No Metered Tollbooths:** An overnight batch job processing thousands of messages on commercial APIs would rack up recurring API bills. With open-weight models, batch overnight inference is completely free.
4. **Predictability:** Closed APIs deprecate models, shift system prompts, and throttle rate limits. Open weights guarantee that your personal agent behaves identically today, tomorrow, and ten years from now.
